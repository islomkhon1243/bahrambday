# Afterglow — новая галерея

Открыть `gallery.html`. Ответ на вопрос входа — `69`. Вход спрашивается при каждом открытии страницы. Это сценарный экран, а не защита: исходный ответ и файлы доступны в статическом сайте. Для настоящей приватности нужна серверная авторизация.

Подготовлено 30 нейтральных мест для обычных фотографий. Старые изображения не подключаются, выбранные ранее файлы браузера не восстанавливаются.

## Постоянные фотографии

Добавляйте фотографии в `dist/assets/photos/`. Редактируйте `dist/gallery-data.js`, например:

```js
window.BAHRAM_GALLERY = [
  { src: 'assets/photos/01.webp', title: 'Вечер с друзьями', caption: 'Один из тех самых дней.', alt: 'Друзья за столом', width: 1600, height: 1067 },
  { src: 'assets/photos/02.jpg', title: 'Твой ракурс', caption: '', alt: 'Портрет Бахрама', width: 1200, height: 1800 }
];
```

Для 30 кадров укажите 30 объектов. Можно добавить больше или меньше: счётчики и просмотр подстроятся. `src: null` оставляет заглушку. `width` и `height` — реальные размеры исходника для сохранения места до загрузки. После загрузки используется естественное соотношение сторон: кадры не обрезаются. В полном просмотре `object-fit: contain`.

Музыка сохранена: `music-config.js`, `experience.js` и Songbird не изменены. Просмотр: стрелки, Esc, свайп, слайд-шоу по 6 секунд. Два режима плотности сетки. Анимации учитывают prefers-reduced-motion.

Публикация Netlify — из `dist`, как и прежде. Вместе с кодом загрузите сами изображения: локальный выбор в браузере в этой версии не используется.

## Горизонтальная обложка в первом экране

Положите PNG или GIF в `dist/assets/`, например `gallery-banner.gif`. В конце `dist/gallery-data.js` заполните:

```js
window.BAHRAM_GALLERY_HERO = {
  src: 'assets/gallery-banner.gif',
  alt: 'Описание картинки'
};
```

Для PNG укажите `assets/gallery-banner.png`. Прозрачность и GIF-анимация сохраняются. Изображение показывается справа от заголовка, на телефоне — под ним, целиком без обрезки. Пока `src: null`, виден нейтральный заполнитель без запросов к отсутствующему файлу. Файл подключается после правильного ответа на входе. При неверном пути остаётся заполнитель.

## Фон из падающих PNG

`dist/gallery-pile-config.js` — отдельные настройки анимации по образцу `bg-pile.html`. PNG падают, подпрыгивают, накапливаются, затем проваливаются волной. По умолчанию используется существующий `assets/spider-logo.png`. Укажите собственные обычные иллюстрации:

```js
images: ['assets/decor/one.png', 'assets/decor/two.png'],
```

Картинки отображаются целиком, с прозрачностью, без обрезки. `cell` — размер, `rate` — частота, `opacity` — прозрачность, `fill` — уровень заполнения, `cycle` — максимальное время до провала, `speed` — скорость, `wave` — провал волной. Максимум 20 разных изображений. Отсутствующие файлы пропускаются. Если нет доступных картинок, фон остаётся пустым.

Фон работает только после входа в галерею; останавливается при закрытии архива, скрытии вкладки и полном просмотре фотографии. Системная настройка уменьшения движения заменяет анимацию неподвижной композицией. Частота ограничена 30 кадрами/с, плотность canvas — 1.5x, число элементов ограничено. Музыка и соседние страницы не изменяются.

## Анимированные GIF в падающем фоне

Фон переведён с canvas на HTML-картинки: GIF воспроизводится самостоятельно, а JavaScript меняет только положение и вращение. В `dist/gallery-pile-config.js` укажите:

```js
images: ['assets/animation.gif', 'assets/sticker.png'],
```

Существующие пути в конфигурации сохранены. Картинки целиком вписываются в клетку, а PNG сохраняют прозрачность. Физика падения, отскок и волновой провал сохранены. На компьютере максимум 120 элементов (параметр `maxItems`, 24–180), на телефоне — максимум 60. Для тяжёлых GIF лучше `rate: 3` и `maxItems: 40`.

Фон скрывается и расчёт движения останавливается при просмотре фотографии, закрытии архива и скрытии вкладки. При prefers-reduced-motion фон отключён полностью, чтобы GIF тоже не отвлекали. Предыдущее описание неподвижной композиции и плотности canvas относится к старой реализации.
